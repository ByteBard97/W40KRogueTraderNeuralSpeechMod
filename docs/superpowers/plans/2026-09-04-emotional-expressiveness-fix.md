# Emotional Expressiveness Fix Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix the TTS pipeline so lines annotated `angry`/`dramatic`/`sarcastic`/etc. actually sound
different from `neutral`, by switching to the Chatterbox variant whose intensity controls are real,
routing to emotion-matched reference clips instead of one clip per speaker, and upgrading the
annotation LLM's delivery-direction language.

**Architecture:** Four independent fixes, each individually shippable and testable: (1) a new
engine adapter for original Chatterbox (500M) alongside the existing Turbo adapter; (2) a
corrected annotation-to-engine-parameter bridge that drops fake emotion tags and drives real
`exaggeration`/`cfg_weight`; (3) a new emotion-matched reference-clip bank built from data this
project already has (real speaker-attributed game audio + existing emotion annotations), consumed
by the sidecar in place of the current single-clip-per-speaker lookup; (4) a rewritten annotation
system prompt that produces concrete acoustic-mechanics delivery direction instead of clinical
emotion labels, for future instruct-capable engines.

**Tech Stack:** Python 3.12, FastAPI (sidecar), `chatterbox` PyPI package (Resemble AI, MIT),
pytest for the pure-logic pieces (`.venv-tts` has all of it already installed).

**Spec:** This session's research conversation (no separate spec doc was written — the research is
extensive and cross-verified; see `docs/research/emotional-expressiveness-prompts.md` for the
original research questions). Key verified facts this plan depends on, so a future reader doesn't
have to re-derive them:
- Chatterbox-**Turbo**'s `exaggeration`/`cfg_weight` are dead code at generation time (confirmed
  directly in the installed `chatterbox/tts_turbo.py` source: `if cfg_weight > 0.0 or exaggeration
  > 0.0 or min_p > 0.0: logger.warning(...ignored)`), and confirmed by Resemble AI's own engineer
  on HF discussion `ResembleAI/chatterbox-turbo/discussions/22`: exaggeration was trained in and
  then deliberately removed because it hurt naturalness at 350M params; "I would recommend using
  the original model if CFG/exaggeration is preferred."
- Original **Chatterbox** (`chatterbox.tts.ChatterboxTTS`, 500M) has real, working
  `exaggeration`/`cfg_weight` — confirmed both in its source (`chatterbox/tts.py`:
  `generate(..., exaggeration=0.5, cfg_weight=0.5)`, no ignore-warning) and by a live test this
  session on an RTX 5080: `exaggeration` 0.15→1.0 roughly doubled RMS loudness (0.047→0.079) and
  pitch mean (109→197 Hz), RTF 0.33-0.48 (faster than real-time).
- Of Chatterbox's 19 bracketed tags that exist as real tokens in `added_tokens.json`
  (`ResembleAI/chatterbox-turbo`, IDs 50257-50275), Resemble's own staff (same discussion tab,
  `discussions/21`) only endorses 9 as "supported": `[clear throat]`, `[sigh]`, `[shush]`,
  `[cough]`, `[groan]`, `[sniff]`, `[gasp]`, `[chuckle]`, `[laugh]` — all nonverbal/sound-effect
  tags. The other 10 (the emotion words: `angry`, `fear`, `surprised`, `whispering`,
  `advertisement`, `dramatic`, `narration`, `crying`, `happy`, `sarcastic`) are real tokens but not
  reliably trained. A live A/B test this session (same line, same voice, tag swapped) found
  `[happy]` and `[crying]` acoustically near-indistinguishable, corroborating this.
  `tools/annotate/schema.py`'s `NONVERBALS` list already matches the real 9-tag set exactly
  (just underscored: `clear_throat`) — that part of the schema was already correct.
- Reference-clip prosody caps zero-shot output regardless of tags/parameters (multiple
  independent sources, including the ExpPro paper, APSIPA 2025) — the fix is emotion-matched
  reference clips, not a single "cleanest" clip reused for every line.
- Concrete acoustic-mechanics delivery instructions (pitch direction, volume, pacing, phonation
  texture) measurably outperform clinical emotion-name descriptions for instruction-following TTS
  (InstructTTSEval benchmark, cited across multiple independent research reports this session).

## Global Constraints

```python
"""Original Chatterbox adapter (Resemble AI, MIT). 500M, working exaggeration/cfg_weight -
unlike Turbo, these are real generation-time controls (see docs/superpowers/plans/
2026-09-04-emotional-expressiveness-fix.md for why this exists alongside chatterbox_turbo.py)."""
import numpy as np


def load():
    import torch
    from chatterbox.tts import ChatterboxTTS
    model = ChatterboxTTS.from_pretrained(device="cuda" if torch.cuda.is_available() else "cpu")
    return model


def synth(model, text, prompt_wav=None, prompt_text=None, exaggeration=None, cfg_weight=None):
    kwargs = {}
    if prompt_wav:
        kwargs["audio_prompt_path"] = prompt_wav
    if exaggeration is not None:
        kwargs["exaggeration"] = exaggeration
    if cfg_weight is not None:
        kwargs["cfg_weight"] = cfg_weight
    wav = model.generate(text, **kwargs)
    return np.asarray(wav.squeeze().cpu().numpy(), dtype=np.float32), model.sr
```

```python
# Chatterbox's only reliably-trained bracketed tags are these 9 nonverbal/sound-effect tokens
# (Resemble AI staff confirmation, HF discussion ResembleAI/chatterbox-turbo/discussions/21).
# Emotion-word tags like [angry]/[sarcastic]/[dramatic] exist as tokens in the checkpoint's
# vocabulary but are not reliably trained - a live A/B test found [happy] and [crying]
# acoustically near-indistinguishable. Emotional intensity is carried by exaggeration/cfg_weight
# instead (only real on original Chatterbox, not Turbo - see the plan header for why).
_CHATTERBOX_NONVERBAL = {"laugh": "laugh", "chuckle": "chuckle", "sigh": "sigh", "gasp": "gasp",
                         "groan": "groan", "sniff": "sniff", "cough": "cough",
                         "clear_throat": "clear throat", "shush": "shush"}


def for_chatterbox(text: str, annotation: dict | None) -> tuple[str, float, float]:
    """Returns (text_with_tags, exaggeration, cfg_weight). No annotation -> pass-through,
    exaggeration=0.5, cfg_weight=0.5 (Chatterbox's own defaults)."""
    if not annotation:
        return text, 0.5, 0.5
    tags = [f"[{_CHATTERBOX_NONVERBAL[nv]}]" for nv in annotation.get("nonverbal", [])
            if nv in _CHATTERBOX_NONVERBAL]
    prefix = " ".join(tags) + " " if tags else ""
    intensity = float(annotation.get("intensity", 0.0))
    exaggeration = min(1.0, 0.4 + 0.6 * intensity)
    cfg_weight = max(0.2, 0.5 - 0.3 * intensity)
    return prefix + text, exaggeration, cfg_weight
```

```python
    "happy": "baseline", "amused": "baseline",
}
BUCKETS = ("high_arousal_aggressive", "high_arousal_agitated", "low_arousal_subdued", "baseline")


def bucket_for_emotion(emotion: str) -> str:
    return EMOTION_TO_BUCKET.get(emotion, "baseline")


def assign_clips_to_buckets(catalog: dict, annotations: dict,
                             min_dur: float = 3.0, max_dur: float = 15.0) -> dict:
    """Group catalog entries by (speaker, bucket) using each clip's OWN annotation. Returns
    {speaker: {bucket: [catalog_entry_with_event_and_guid, ...]}}. Entries whose text_key has
    no annotation record, or whose duration is out of range, are skipped - not an error, just
    not usable as a reference clip."""
    out: dict[str, dict[str, list]] = {}
    for event, c in catalog.items():
        if not (min_dur <= c.get("duration", 0) <= max_dur):
            continue
        if not c.get("texts"):
            continue
        guid = c["texts"][0].get("guid")
        ann = annotations.get(guid)
        if not ann:
            continue
        bucket = bucket_for_emotion(ann.get("emotion", "neutral"))
        speaker = c["speaker"]
        out.setdefault(speaker, {b: [] for b in BUCKETS})
        out[speaker][bucket].append({**c, "event": event, "guid": guid,
                                     "annotated_emotion": ann.get("emotion"),
                                     "annotated_intensity": ann.get("intensity")})
    return out


def main() -> None:
    ap = argparse.ArgumentParser()
    ap.add_argument("--top", type=int, default=4, help="clips to keep per speaker per bucket")
    ap.add_argument("--min-dur", type=float, default=3.0)
    ap.add_argument("--max-dur", type=float, default=15.0)
    args = ap.parse_args()

    catalog = json.loads((VOICES / "catalog.json").read_text(encoding="utf-8"))
    annotations = json.loads((ROOT / "data/annotations/annotations.enGB.json").read_text(encoding="utf-8"))

    grouped = assign_clips_to_buckets(catalog, annotations, args.min_dur, args.max_dur)

    out_root = VOICES / "emotion_banks"
    result: dict[str, dict[str, list]] = {}
    for speaker, buckets in sorted(grouped.items()):
        result[speaker] = {}
        for bucket, entries in buckets.items():
            scored = []
            for c in entries:
                try:
                    x, sr = load_wav(VOICES / c["wav"])
                except Exception:
                    continue
                sc = score_clip(x, sr, c["texts"][0]["text"])
                if sc.get("ok"):
                    scored.append((sc["score"], c, sc))
            scored.sort(key=lambda t: -t[0])
            chosen = scored[: args.top]
            sdir = out_root / re.sub(r"[^A-Za-z0-9_-]", "_", speaker)
            sdir.mkdir(parents=True, exist_ok=True)
            written = []
            for rank, (score, c, sc) in enumerate(chosen, 1):
                dst = sdir / f"{bucket}_{rank:02d}_{Path(c['wav']).name}"
                dst.write_bytes((VOICES / c["wav"]).read_bytes())
                written.append({"rank": rank, "event": c["event"], "wav": str(dst.relative_to(VOICES)),
                                "text": c["texts"][0]["text"],
                                "annotated_emotion": c["annotated_emotion"],
                                "annotated_intensity": c["annotated_intensity"], **sc})
            result[speaker][bucket] = written
        counts = {b: len(result[speaker][b]) for b in BUCKETS}
        print(f"{speaker}: {counts}")

    (out_root / "prompts.json").write_text(json.dumps(result, ensure_ascii=False, indent=1), encoding="utf-8")


if __name__ == "__main__":
    main()
```
